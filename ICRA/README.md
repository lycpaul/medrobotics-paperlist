# ICRA Paper Lists

Accepted-paper lists for the **ICRA** (IEEE International Conference on Robotics
and Automation) conference. For each year there is a Markdown table
(`ICRA<YEAR>_Paper_List.md`) for quick browsing and a
`ICRA<YEAR>_Paper_List_with_Abstract.csv` with the full records including
abstracts.

## Statistics

| Year | Papers | Program sessions |
| --- | --- | --- |
| 2026 | 2,960 | 36 \* |
| 2025 | 2,091 | 319 |
| 2024 | 2,392 | 274 |
| 2023 | 1,655 | 191 |
| **Total** | **9,098** | |

"Papers" counts distinct papers (unique titles) in each year's
`_with_Abstract.csv`. "Program sessions" counts the distinct session/track
labels papers are grouped under, a rough proxy for topic breadth.

\* ICRA 2026 is a preliminary program. Most papers sit in six broad
"Interactive Session 1–6" blocks. The rest are in "Late Breaking Results 1–6",
"Award Finalists 1–4", and 20 small topic sessions (e.g. "Medical Robotics I",
"Field and Space Robotics"), so the session count is much lower than in
earlier years. The CSV has 2,965 rows. Four papers are listed in more than one
interactive session and one is listed twice, so they are counted once each.

> Note: two `.md` lists disagree with their CSV, so the figures above come
> from the CSVs.
>
> - `ICRA2025_Paper_List.md` currently contains a copy of the **IROS 2025**
>   list (identical to `IROS/IROS2025_Paper_List.md`) and should be
>   regenerated.
> - `ICRA2026_Paper_List.md` is a different snapshot of the program with
>   2,830 rows. It has no Late Breaking Results entries (135 rows in the CSV).
